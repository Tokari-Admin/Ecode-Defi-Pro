# **App Name**: Défi45j

## Core Features:

- Authentication Page: Enable user registration and login via email, password (with show/hide option), and access code.
- Onboarding Process: Collect mandatory user information (Name, Surname, Sponsor) upon first login.
- Dashboard: Main user interface with header (User icon, notification bell, fullscreen button) and retractable sidebar.
- Sidebar Navigation: Provide navigation links in the sidebar: Dashboard and Mes actions.

## Style Guidelines:

- Background color: Light grey (#F4F5F8).
- Text color: Dark grey (#222326).
- Primary colors: Dark blue (#10496C) and reddish-pink (#E8335D) for accents.
- Body and headline font: 'PT Sans', a humanist sans-serif, for a modern yet approachable feel.
- Use a 'Fusée' (rocket) icon to represent the app; ensure User, Notification, and Fullscreen icons are clear and consistent.
- Retractable sidebar layout to maximize content area.
- Subtle transitions and animations for user interactions, like sidebar collapse/expand.
